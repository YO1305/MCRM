# Каталог Бахмал

Интерактивная система каталога для Bahmal Home.

## Статус

Ожидаем техническое задание (ТЗ). После получения ТЗ — декомпозиция, реализация и тесты.

## Связь с текущим репозиторием

Каталог уже частично реализован в основном приложении **bahmal-crm**:

| Область | Путь |
|--------|------|
| Админка: каталоги и КП | `src/pages/Catalogue.tsx` |
| Публичная страница по slug | `src/pages/PublicCatalogue.tsx` |
| Компоненты | `src/components/catalogue/` |
| Firestore / хуки | `src/hooks/useCatalogues.ts`, `src/types/catalogue.types.ts` |

Новая интерактивная система может развиваться здесь (`katalog-bahmal/`) и/или в указанных модулях CRM — по ТЗ.
